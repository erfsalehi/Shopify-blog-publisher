Paste the URL of a collection on the manufacturer's own site. Every product in it is read — description, photographs, specification tables, and the PDFs they link — the documents are downloaded and their text used, and a product is created here with its own copy, SEO fields, tags, an FAQ, and links to the rest of the range. Products are created as drafts unless you change that below, so nothing appears on the storefront until you say so. Prices are never set: manufacturers don't publish yours.

Import a collection

The page listing the range, not one product. A Shopify manufacturer site gives the most complete result — the whole product, images and all, comes from their own feed.

A manufacturer's internal name for a range is rarely what a customer searches for. This is the title of the collection created here.

Required, because every product name starts with it — "Brand Collection Type Size - Colour". It used to say "left blank: taken from the source", which is true of a Shopify supplier and false of most others: a Magento catalogue publishes no brand anywhere a scraper can read, so leaving it blank silently dropped the brand from every name in the range.

A ceiling, in case the URL turns out to be the whole catalogue.

Either way nothing is removed. Products already in the store are left exactly as they are and simply added to the collection, and a product the supplier has since dropped stays on the store — their catalogue is not a record of what you sell.

An existing page is added to, never rewritten. Untick this to add products to a collection you maintain by hand — or for an older range whose page you would rather build yourself.

The safe way to try a supplier's site for the first time: you see exactly what was extracted from each product page and what the description would say, with nothing sent to Shopify.

The storefront filter fields an import fills — brand, type, width, colour, thickness — are yours: you chose their type and gave them the storefront access a filter needs. So an import fills them and never creates them, and it needs to be told their keys in Product import settings. This is where to read them off.
